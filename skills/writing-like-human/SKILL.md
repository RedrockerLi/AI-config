# 降AI率写作 (Writing Like Human)

把 AI 生成的中文/英文文字改写成自然的、像人类研究者写出来的文体。

## 核心原则

**去AI化 ≠ 压缩。** 除非明确要求缩写，否则不主动删除事实、数据、限定条件和解释句。语言调整只服务于表达自然、逻辑清楚和口径稳定，不为了显得精炼而压掉必要信息。

---

## 一、中文：禁用表达

### 1.1 机械过渡词（禁止使用）

以下词在段落中必须避免，用语义自然的承接替代模板衔接：

| 禁用 | 
|------|
| 首先、其次、最后 |
| 此外、另外、除此之外 |
| 接下来、然后、接着 |
| 总之、综上所述 |
| 与此同时、另一方面 |

### 1.2 空壳强调句（禁止使用）

这些句式没有任何实质内容，删除后不影响语义：

| 禁用 |
|------|
| 值得注意的是 |
| 需要指出的是 |
| 重要的是 |
| 必须强调的是 |
| 显而易见 |
| 毋庸置疑 |
| 众所周知 |

### 1.3 空洞修饰词（无数据支撑时禁用）

| 禁用 | 替换方式 |
|------|----------|
| 非常、极其、十分、相当 | 用具体数据或删除 |
| 显著提升、大幅改善 | 给出百分比或量值 |
| 很重要、具有关键意义 | 解释为何重要，或删除 |

### 1.4 主观引导句（论文正文禁用）

| 禁用 | 替换 |
|------|------|
| 我认为 | 本文认为 / 删除直接陈述 |
| 我觉得 | 删除直接陈述 |
| 我个人看法是 | 删除直接陈述 |

## 二、英文：禁用表达

### 2.1 AI 味浓厚词汇（替换表）

| 避免使用 | 推荐替换 |
|----------|----------|
| leverage | use, employ |
| delve into | investigate, examine |
| tapestry | context, framework |
| underscore | highlight, show |
| pivotal | important, key |
| nuanced | detailed, subtle |
| foster | encourage, support |
| elucidate | explain, clarify |
| intricate | complex, detailed |
| paramount | important, critical |
| Furthermore / Moreover | Also / In addition (适度使用) |
| It is worth noting that | Note that / 直接陈述 |
| First and foremost | First / 直接陈述 |

### 2.2 机械过渡词（英文）

禁用：`First and foremost`, `To begin with`, `Moreover`, `Furthermore`, `Last but not least`, `In conclusion`

### 2.3 禁用项列表转化

英文正文中不要使用 `\item` 列表堆叠，转为连贯段落。

## 三、中文期刊论文的自然行文原则

中文期刊论文不追求每句话都极度精简。更自然的写法通常是：

1. 先交代研究对象、资料范围或问题背景
2. 再说明处理方法、结果现象和判断边界
3. 句子可以略长，段落中可以有必要的承接、限定和少量重复
4. 只要主语明确、关系清楚、读者能顺着研究过程理解即可

**去AI化的重点是减少：模板化、翻译腔、过度概括、空泛拔高**

**应当保留的：** 对象、时间范围、样本口径、方法条件、指标含义、实验边界、因果关系

**不要做的：**
- 不要改成机械的"背景-方法-结果-意义"句组
- 不要让每句话都呈现"对象-动作-结论"的功能句
- 不要删除所有修饰语

## 四、常见AI化症状与处理

| 症状 | 处理方式 |
|------|----------|
| 句式像英文直译 | 改为中文常用语序：先说明对象和现象，再给判断 |
| 段落过度模板化 | 取消固定的"背景-方法-结果-意义"节奏，保留解释句和承接句 |
| 改写后信息变少 | **补回**研究对象、数据范围、方法条件、指标口径和结论边界 |
| 审稿回复口吻 | 将"该指标反映的是""不能理解为"改成正文叙述，如"本文将…作为参照" |
| 空泛拔高 | 用具体指标、现象或限定替代"显著""关键""重要意义"等泛化词 |
| 过度压缩 | 若改短后丢失信息，恢复必要说明；去AI化不等于越短越好 |

### 当用户反馈"太AI""太精简""像翻译"时

处理顺序：
1. **先补回**必要信息（数据、条件、边界）
2. **调整为**中文自然语序
3. **再收束**过强判断
4. **不要**继续简单删词减句

---

## 五、句法与信息密度

1. 一句话围绕一个主要关系展开，必要时保留条件、范围和解释，不强行压成短句
2. 保留方法、条件、对象和数据，不用"很多""较大提升"等模糊表述
3. 长短句交替，避免等长句连续出现
4. 列表转段落时补足主语、谓语和连接成分
5. 用"本文""实验结果表明""表X显示"等客观主语，但避免连续重复同一模板

---

## 六、输出排版规范

### 正文规范

1. **正文不使用加粗和斜体**
2. **段落之间必须空一行**
3. **正文优先连贯段落，不使用项目符号堆叠**
4. 同一段尽量保持单一中心观点
5. 避免把一个完整观点拆成过多短段

### 列表仅限以下场景

- 计划文档
- 检查清单
- 参数配置
- 操作步骤

**论文正文不用列表。**

---

## 七、列表转段落

❌ **错误写法：**
```
本研究贡献如下：
- 提出新方法
- 完成自动化流程
- 验证有效性
```

✅ **推荐写法：**
```
本研究提出了一种新方法，并将其整合为可执行的自动化流程。
实验结果显示，该方法在目标任务上具有稳定增益，验证了其可行性与应用价值。
```

---

## 八、段落构建规则

一个标准段落包含三部分：

1. **主题句** — 本段核心结论
2. **支撑句** — 依据、证据、解释
3. **收束句** — 过渡或小结

建议长度：中文 150-300 字，英文 100-200 词。

## 九、去AI化改写提示词模板

### 9.1 中文去AI化（信息保留版）

直接复制使用，替换 `【待改写文本】`：

```markdown
# Role
你是一位熟悉中文期刊论文写法的科研写作编辑，能够在不改变技术含义和数据口径的前提下，
降低中文论文段落中的AI腔、翻译腔和模板化表达。

# Task
请改写以下中文论文段落，使其更接近中文期刊论文中自然、稳妥、可提交的正文表达。

# Constraints
1. 去AI化不等于压缩。除非明确要求缩写，不要主动删减事实、数据、限定条件和解释句。
2. 必须保留研究对象、数据范围、样本口径、方法条件、指标含义、实验边界、结论限制和专有名词。
3. 使用连续段落，不使用项目符号，不使用加粗、斜体。
4. 避免"首先、其次、最后、此外、另外、接下来、总之"等机械连接词，改用语义自然的承接。
5. 避免"值得注意的是、需要指出的是、重要的是、必须强调的是"等空壳句式。
6. 减少英文直译式语序，不把每句话都改成"对象-动作-结论"的机械短句。
7. 避免审稿回复式表达。正文中不要写成"该指标反映的是""不能理解为""用于避免口径悬空"，
   应改为自然叙述。
8. 保持判断克制。涉及效果、提升、贡献或应用意义时，优先使用具体指标、现象和边界支撑，
   不写空泛拔高。
9. 如果原文虽然略显啰嗦但信息完整、语序自然，可以只做轻微调整；不要为了显得精炼而压掉必要信息。

# Input
【待改写文本】

# Output
- Part 1 [Refined Text]：改写后的中文正文
- Part 2 [Modification Log]：说明主要改动，特别标出是否处理了翻译腔、模板腔、
  审稿回复口吻或空泛判断；若原文已自然，输出"[检测通过]"
- Part 3 [Information Check]：确认是否保留了关键对象、数据、方法、指标和边界；
  如存在信息缺失风险，明确指出
```

### 9.2 英文去AI化

```markdown
# Role
你是计算机科学领域的资深学术编辑，专注于提升论文自然度。

# Task
请对以下英文论文段落进行"去AI化"重写。

# Constraints
1. 避免使用被滥用的词汇（leverage, delve into, tapestry, underscore, pivotal, nuanced, etc.）
2. 将item列表内容转化为连贯段落
3. 删除机械连接词（First and foremost, Moreover, Furthermore 等）
4. 原文已自然则保留

# Output
- Part 1 [LaTeX]：重写后的文本
- Part 2 [Translation]：对应中文直译
- Part 3 [Modification Log]：调整说明或"[检测通过]"
```

## 十、三轮质量自检

改写完成后逐轮检查：

### 第一轮：结构检查

- [ ] 是否存在正文列表化（误用项目符号堆叠观点）
- [ ] 段落是否围绕单一中心
- [ ] 章节逻辑是否连续
- [ ] 是否写成机械的"背景-方法-结果-意义"模板段

### 第二轮：语言检查

- [ ] 是否出现禁用过渡词（首先/其次/此外/总之等）
- [ ] 是否出现禁用强调句式（值得注意的是/需要指出的是等）
- [ ] 是否存在无信息量形容词堆积（非常/极其/十分等）
- [ ] 是否出现主观化表述（我认为/我觉得等）
- [ ] 是否存在翻译腔、英文语序或审稿回复式表达
- [ ] 是否因过度压缩丢失研究对象、数据范围、方法条件、指标口径或结论边界
- [ ] 是否用具体数据和现象支撑"提升""有效""稳定"等判断

### 第三轮：排版检查

- [ ] 是否有无意义加粗或斜体
- [ ] 段间是否统一空一行
- [ ] 标点与中英文空格是否一致

## 十一、引用与事实（硬门槛）

1. **绝不编造文献或数据**
2. 引用格式与全文统一
3. 含有结论性表述时，优先给出处或数据
4. 英文文献可检索后引用，中文文献优先让用户提供来源
5. 任何引用必须可追溯（作者、年份、出处至少完整两项）

---

## 执行约束

1. 用户明确要求保留特定风格时，以用户要求优先
2. 原文已自然流畅的段落，不做过度修改，输出"[检测通过]"
3. 每次改写必须输出改动日志，说明改了什么、为什么改
